НМТ ТРЕНАЖЕР • СОВА-ЛІЗА (версія 3.5 для macOS)
====================================================

Що оновлено у цій збірці для Mac:
• Відновлено чистий інтерфейс і надійне розташування нижніх кнопок (нічого не зникає і не перекривається).
• 10 рівнів підказок від Сови-Лізи (1/10 — легкий натяк, 10/10 — повна відповідь із розповіддю та поясненням правил).
• Адаптовано блок опрацювання та виправлення помилок на ідентичних прикладах під будь-який розмір вікна (плюс кнопка «⤢ На весь екран»).
• Плавна анімована прокрутка до самого низу (трекпад, колесо миші, перетягування повзунка або PageDown / End).
• Усі 12 предметів НМТ, 189 завдань 2022–2026 рр., 40 генераторів і шкала 100–200.
• Результати тренувань, звіти та власні банки завдань зберігаються автоматично й зашифровано.
• Профілі учнів («Хто займається?»): для створення потрібні лише ім’я та за бажанням PIN-код;
  аватар, свої предмети, цілі 100–200 і дату НМТ можна задати потім у «Профіль → Редагувати профіль».
• Особистий кабінет: рівень і ціль з кожного предмета, графік прогресу, слабкі теми з кнопкою
  «Потренувати» та історія тренувань зі звітами. Забутий PIN відновити не можна — лише видалити профіль.

Як відкривати на Mac подвійним кліком:
1. Розпакуйте архів NMT_Sova_Tutor_Mac-v6.zip ПОВНІСТЮ: поруч із файлом «nmt_tutor_mac.py»
   має лежати папка «nmt_tutor» (у ній увесь код і база завдань). Без цієї папки програма не запуститься.
2. Встановіть офіційний Python 3.13 або новіший (перевірено на 3.14) для macOS із сайту
   python.org/downloads/macos/ (він автоматично встановлює «Python Launcher» та бібліотеку вікон Tkinter).
   Важливо: на нових macOS старіші версії (наприклад, Python 3.11 зі старою бібліотекою Tk 8.6)
   погано обробляють кліки — кнопки спрацьовують не з першого разу й лише посередині.
   Python із Homebrew не підходить: у ньому немає бібліотеки вікон Tkinter.
3. Один раз встановіть пакет шифрування. Відкрийте «Термінал» і виконайте команду
   (замініть 3.14 на вашу версію):
       /Library/Frameworks/Python.framework/Versions/3.14/bin/python3.14 -m pip install cryptography
   Без нього програма запропонує працювати без збереження результатів.
4. Натисніть правою кнопкою миші на «nmt_tutor_mac.py» -> «Властивості» (Get Info / ⌘I) ->
   «Відкривати в програмі» (Open with) -> оберіть «Python Launcher» із папки
   «Програми/Python 3.14» -> «Змінити для всіх».
   Після цього «nmt_tutor_mac.py» відкриватиметься звичайним подвійним кліком!

Де зберігаються дані:
• Папка Документи/NMT_Tutor, файл «nmt_tutor_data.sqlite3» — зашифрована база (AES-256-GCM)
  з профілями, результатами, звітами та власними банками. Ключ шифрування зберігається у «Зв’язці ключів»
  (Keychain) під назвою «NMT_Tutor», тому відкрити базу можна лише на цьому Mac у вашому обліковому записі.
• Звіти й банки зі старої версії (файли .json і nmt_report_*.txt у цій папці) під час першого запуску
  автоматично копіюються в зашифровану базу. Самі старі файли не змінюються й не видаляються —
  за бажанням їх можна видалити вручну.
• Кнопка «💾 Зберегти звіт (.txt)» і далі зберігає звичайний текстовий звіт туди, куди ви оберете.

Консольний режим (без вікон): python3 nmt_tutor_mac.py --cli
