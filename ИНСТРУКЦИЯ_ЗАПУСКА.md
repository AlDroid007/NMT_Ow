# Как запустить «НМТ Тренажёр • Сова-Лиза» на другом компьютере

Программа написана на Python и запускается на macOS и Windows без установки — нужен только Python
с сайта python.org и один дополнительный пакет `cryptography` (для шифрования данных пользователя).

Устройство проекта (что где лежит) описано в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
Как включить хмарное сохранение (Supabase) — [`docs/CLOUD_SETUP.md`](docs/CLOUD_SETUP.md).

---

## 1. Скачать проект

**Вариант А — архив (проще всего).**
Откройте https://github.com/AlDroid007/NMT_Ow, выберите ветку `develop`, нажмите
**Code → Download ZIP** и распакуйте архив **полностью**.

**Вариант Б — через git** (если git установлен):

```bash
git clone -b develop https://github.com/AlDroid007/NMT_Ow.git
```

После распаковки в папке должны лежать рядом:

```
nmt_tutor_mac.py      ← файл, который запускается
nmt_tutor/            ← весь код программы и база заданий (без неё ничего не запустится)
owl_icon.png, AppIcon.icns
```

## 2. macOS (MacBook)

### 2.1. Установить Python

1. Скачайте установщик **Python 3.13 или новее** (рекомендуется последняя версия, проверено на 3.14)
   с https://www.python.org/downloads/macos/ — файл `.pkg`.
2. Запустите его и пройдите установку (понадобится пароль администратора Mac).

> ⚠️ Нужен именно Python с **python.org**:
> - Python из Homebrew не подходит — в нём нет библиотеки окон Tkinter, программа не откроется.
> - Старые версии (например, 3.11) на новых macOS работают с ошибками: кнопки нажимаются
>   не с первого раза и только по центру.

### 2.2. Установить пакет шифрования

Откройте **Терминал** (Программы → Утилиты → Терминал) и выполните команду
(если версия Python другая — замените `3.14` в обоих местах):

```bash
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3.14 -m pip install cryptography
```

Полный путь нужен, чтобы пакет установился именно в Python с python.org, а не в Homebrew-версию.

### 2.3. Запуск двойным кликом

1. Нажмите правой кнопкой на `nmt_tutor_mac.py` → **Свойства** (Get Info, ⌘I).
2. В разделе **Открывать в программе** (Open with) выберите
   `Программы → Python 3.14 → Python Launcher`.
3. Нажмите **Изменить для всех** (Change All).

Теперь `nmt_tutor_mac.py` открывается обычным двойным кликом.

### 2.4. Запуск из Терминала (если двойной клик не сработал)

```bash
cd путь/к/папке/NMT_Ow
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3.14 nmt_tutor_mac.py
```

При первом запуске macOS может спросить разрешение на доступ к **Связке ключей** —
нажмите **Разрешить** (или **Всегда разрешать**): там хранится ключ шифрования ваших данных.

## 3. Windows

### 3.0. Готовая сборка — без установки Python (рекомендуется, например для художника)

GitHub сам собирает папку с программой при каждом пуше в `develop`/`main`: внутри уже есть Python,
окна и шифрование — на компьютере ничего ставить не нужно.

**Скачать (нужен вход в GitHub с доступом к репозиторию):**
1. https://github.com/AlDroid007/NMT_Ow/actions → слева **Build Windows app**.
2. Откройте последний запуск с зелёной галочкой → внизу блок **Artifacts** →
   **NMT_Sova_Tutor_Windows** (скачается zip ≈ 15–20 МБ). Хранится 90 дней.
3. Этот zip можно отправить человеку как есть (почта, Telegram, Google Drive).

Собрать заново вручную: на той же странице **Build Windows app → Run workflow**.

**Запуск на компьютере с Windows:**
1. Распаковать zip **полностью** (правой кнопкой → «Извлечь всё»), не запускать из окна архива.
2. Папка `NMT_Sova_Tutor` → двойной клик по `NMT_Sova_Tutor.exe` (значок совы).
3. Если появится синее окно «Windows защитила ваш компьютер» (SmartScreen — у программы нет
   платной цифровой подписи): **Подробнее → Выполнить в любом случае**. Только при первом запуске.
4. Ярлык: в программе **Файл → Створити ярлик на Робочому столі**.

Папку `_internal` рядом с exe не удалять. Подробности — в файле `ПРОЧИТАЙ_МЕНЯ.txt` внутри сборки.

Пункты 3.1–3.3 ниже нужны только для запуска из исходников.

### 3.1. Установить Python

1. Скачайте **Python 3.13 или новее** с https://www.python.org/downloads/windows/
   («Windows installer (64-bit)»).
2. В первом окне установщика **обязательно отметьте** галочку
   **Add python.exe to PATH**, затем нажмите **Install Now**.
   Tkinter (библиотека окон) устанавливается автоматически.

### 3.2. Установить пакет шифрования

Откройте **Командную строку** (Win + R → `cmd` → Enter) и выполните:

```bash
py -m pip install cryptography
```

### 3.3. Запуск

- **Двойной клик** по `nmt_tutor_mac.py` — откроется программа
  (вместе с ней может появиться чёрное окно консоли — не закрывайте его, пока работаете).
- **Без окна консоли** — из Командной строки в папке проекта:

  ```bash
  pyw nmt_tutor_mac.py
  ```

- **Ярлык на Рабочем столе**: в программе откройте меню **Файл → Створити ярлик на Робочому столі** —
  дальше запускайте с этого ярлыка (консоль не появляется).

Если двойной клик открывает файл в редакторе, а не запускает программу: правой кнопкой по
`nmt_tutor_mac.py` → **Открыть с помощью** → **Python** («Python Launcher for Windows», синий-жёлтый значок Python)
→ отметьте «Всегда использовать это приложение».

## 4. Профили и личный кабинет

- При запуске программа спрашивает **«Хто займається?»**. В первый раз — сразу предлагает создать профиль:
  нужны только имя и, по желанию, PIN-код из 4 цифр. Пока профиль не выбран, в меню нет учебных разделов.
- Аватар, свои предметы, цели (бал 100–200) и дату НМТ задают потом: **Профіль → Редагувати профіль**.
- На одном компьютере может быть несколько профилей (например, двое детей) — у каждого свои результаты,
  отчёты и банки заданий.
- Результаты, накопленные до появления профилей, автоматически переходят к **первому** созданному профилю.
- **Особистий кабінет** (кнопка с аватаром на экране выбора предметов или меню **Профіль**): уровень и цель
  по каждому предмету, график прогресса, слабые темы с кнопкой «Потренувати», история тренировок с отчётами.
- Сменить профиль — меню **Профіль → Змінити профіль**.
- **Забытый PIN восстановить нельзя** (хранится только в зашифрованном виде): такой профиль можно только
  удалить вместе с его результатами (ссылка «Забули PIN?» в окне ввода PIN).

## 5. Где хранятся данные

| | macOS | Windows |
|---|---|---|
| Папка данных | `~/Документы/NMT_Tutor` | `Документы\NMT_Tutor` |
| База (профили, результаты, отчёты, свои банки) | `nmt_tutor_data.sqlite3` — зашифрована (AES-256-GCM) | то же |
| Ключ шифрования | Связка ключей macOS, запись `NMT_Tutor` | файл `.nmt_tutor_key` в папке данных, защищён средствами Windows (DPAPI) |

**Важно при переносе на другой компьютер.** Ключ привязан к компьютеру и учётной записи, поэтому
скопированную базу на новом компьютере открыть нельзя. Программа в этом случае не удаляет её,
а переименовывает в `nmt_tutor_data.sqlite3.unreadable-…` и начинает новую базу.
Свои банки заданий переносите как `.json`-файлы: **Файл → Додати свій банк (.json)**.

## 6. Без окон (консольный режим)

Работает даже без Tkinter и без `cryptography` (данные при этом не сохраняются):

```bash
# macOS
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3.14 nmt_tutor_mac.py --cli
# Windows
py nmt_tutor_mac.py --cli
```

## 7. Частые проблемы

| Что происходит | Что делать |
|---|---|
| «Не знайдено папку nmt_tutor…» | Архив распакован не полностью: папка `nmt_tutor` должна лежать рядом с `nmt_tutor_mac.py`. |
| «Потрібен пакет cryptography» | Выполните команду установки из п. 2.2 / 3.2 для того же Python, которым запускаете. Можно нажать «Да» и работать без сохранения результатов. |
| `error: externally-managed-environment` (macOS) | Команда попала в Homebrew-Python. Используйте полный путь из п. 2.2. |
| `No module named pip` сразу после установки Python | Подождите окончания установки и повторите команду. |
| `No module named tkinter` | Python не с python.org (например, Homebrew). Установите Python с python.org. |
| Кнопки нажимаются не с первого раза (macOS) | Старый Python (3.11 и ниже). Установите 3.13+ и переключите Python Launcher (п. 2.3). |
| Окно появилось где-то за другими окнами | Найдите значок Python в Dock (ракета) или на панели задач Windows. |
