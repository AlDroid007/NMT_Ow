## Этапы

### 1. Облачная база и синхронизация — ✅
- Supabase (PostgreSQL + вход + правила доступа RLS). Схема — [`DATABASE.md`](DATABASE.md): профиль,
  `profile_meta` (JSON: серия дней, медали…), тренировки `sessions` → итоги по предметам, каждый ответ,
  каждая подсказка; накопления `profile_subject_stats` (считает сервер); заготовки для покупок; роль
  админа и представления для админки; удаление аккаунта (требование App Store).
- Вход по почте с 6-значным кодом (письма через Brevo); одна почта = один профиль.
- Тренировка начинается только с интернетом (`begin_session`), сдаётся одним вызовом `submit_session`.
- Осталось: свой домен для писем; имя и почта в политике конфиденциальности, публикация на GitHub Pages.

### 2. Веб-версия — 🚧
Подробно — [`WEB.md`](WEB.md).
- Vue 3 + TypeScript + Ionic Vue, Pinia, supabase-js; статический сайт на **Cloudflare Pages**
  (бесплатно, превью-ссылка на каждую ветку). Сервер не нужен — сайт ходит в Supabase напрямую.
- Логика тренажёра переписывается на TypeScript 1:1 с Python (`engine`, `hints`, `generators`, `cabinet`);
  задания и шкалы 100–200 переезжают в `web/` одним выгрузом из Python. Паритет проверяют тесты на
  эталонах, выгруженных из Python.
- Только со входом в облако: одна почта = один профиль, без PIN и локальных профилей.
- Весь функционал десктопа: кабинет (график, слабые темы, «Потренувати», история), выбор предметов и
  режима, тренировка с 10 уровнями подсказок и похожими примерами, итоги, отчёт, работа над ошибками,
  профиль, удаление данных из облака.
- Вёрстка mobile-first (iPhone в Safari) — это и есть будущий интерфейс iOS.

### 3. iOS через Capacitor и App Store — ⏳
- Capacitor собирает из `web/` настоящее iOS-приложение (Xcode, .ipa): нативная оболочка, системный
  WebView, плагины для нативных функций (покупки, push, Sign in with Apple, Keychain).
- Нужен Apple Developer Program ($99/год); тестеры — через TestFlight.
- Правило App Store 4.2 («не просто сайт в обёртке»): нативный вид (Ionic), логика внутри приложения,
  покупки и push. Иконка, экран запуска, политика конфиденциальности, анкета о данных (App Privacy).
- Заменяет прежний план BeeWare Toga + Briefcase.

### 4. Банк заданий в базе — ⏳
- Таблица `tasks` с версиями; приложение скачивает обновления и кэширует их, встроенный JSON — запасной вариант.
- Настройки генераторов (включить/выключить) через базу.

### 5. Админка на Vue 3 — ⏳
- Вход админа, статистика учеников (прохождение, баллы, слабые темы, подсказки) — представления
  `admin_students`, `admin_sections`, `admin_hint_levels` уже в схеме.
- Редактор заданий и примеров (после этапа 4). Может переиспользовать компоненты и ядро из `web/`.

### 6. Покупки — ⏳
- Лимит бесплатных тренировок в день, предметы на неделю, пакеты доп. тренировок.
- В iOS — StoreKit (через RevenueCat или плагин Capacitor), проверка чеков на сервере (Supabase Edge
  Function); таблицы `products`, `purchases`, `entitlements`, `session_credits` уже в схеме; лимит — в `begin_session`.
- Решить: какие предметы бесплатные, что расходует лимит, что видно в веб-версии.
- Награды и медали за баллы — на сервере, в `profile_meta.data`.

### 7. Вход через Google и Apple — ⏳
- Через Supabase Auth, привязка к уже существующему облачному аккаунту.
- Если в iOS есть вход через Google, App Store требует и Sign in with Apple.

### 8. Архив десктопа — ⏳
- Когда веб-версия пройдёт проверку паритета, `nmt_tutor/` (Tkinter, PyInstaller) уходит в ветку
  `archive/desktop`, Windows-сборка в CI отключается.

## Десктоп (Python, `nmt_tutor/`) — 🧊 заморожен
- Новых функций нет, только исправление серьёзных ошибок.
- Остаётся эталоном для проверки порта на TypeScript и рабочей сборкой для тестеров, пока веб не покроет всё.
- Облако общее: профиль с компьютера открывается в веб-версии со всей историей.
