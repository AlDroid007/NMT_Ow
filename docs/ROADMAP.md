## Этапы

### 1. Облачная база и синхронизация — 🚧 код готов, нужен проект Supabase
- Supabase (PostgreSQL + вход + правила доступа RLS), выбран из-за будущей админки на Vue 3
  (официальная JS-библиотека, статистика обычным SQL) и встроенного входа через Google/Apple.
- Схема — [`DATABASE.md`](DATABASE.md): профиль, `profile_meta` (JSON: серия дней, медали…),
  тренировки `sessions` (начало/конец) → итоги по предметам, каждый ответ, каждая подсказка;
  накопления `profile_subject_stats` (считает сервер); заготовки для покупок; роль админа и
  представления для админки; удаление аккаунта (требование App Store).
- Вход по почте с 6-значным кодом; одна почта = один профиль; восстановление на другом компьютере.
- Тренировка профиля с облаком начинается только с интернетом (`begin_session`), сдаётся одним
  вызовом `submit_session`; серия дней подряд считается на сервере и видна в кабинете.
- Свои банки заданий скрыты (ученики работают только со встроенными заданиями), отчёты остаются локально.
- Осталось: создать проект и подключить по [`CLOUD_SETUP.md`](CLOUD_SETUP.md), свой SMTP для писем,
  политика конфиденциальности.

### 2. Учёт ответов и подсказок — ✅ сделан вместе с этапом 1

  открытая подсказка записываются и уходят в облако вместе с тренировкой.

### 5. Покупки — ⏳
